1. Welcome

Welcome to Naukri Update. This application is designed to help you automate selected Naukri profile updates directly and safely from your own computer.

The application runs locally on your machine. There is no external database or server managing your data. You control your Naukri account, your resume, what automation features are enabled, when they run, and where your settings are stored.

2. What This App Does

This application implements two separate profile optimization automations:

Resume Headline Auto-Refresh

The Resume Headline automation updates your headline text by dynamically adding or removing a trailing dot. This action forces Naukri's system to record a new "last updated" timestamp on your profile, pushing you higher in search rankings when recruiters search for candidates. The application performs the update and immediately verifies the result on your profile.

Resume PDF Daily Upload

The Resume Update automation uploads your selected resume PDF file to your Naukri account according to a configured schedule. The upload process waits for the file to be completely sent and verified by Naukri before completing the task. To prevent duplicate warning errors on Naukri, the application automatically appends the current date to the file name (e.g. YourName_Resume_29-08-2026.pdf) during the upload process. You do not need to rename your local file manually.

3. How It Works

The application operates entirely on your local machine using an isolated, dedicated Chrome browser session. Below is the system architecture showing how different local components interface directly with Naukri.com without any remote proxies or telemetry.

Local Architecture & Data Flow

Electron GUI The desktop control dashboard used to view logs, check connection status, and trigger updates.
Config & Credentials Stored locally in your AppData folder. Credentials file permissions are secured (chmod 0600 on Linux/macOS).
Playwright Engine Controls the local Chrome instance via CDP (port 9222) headlessly or headfully.
OS Background Task Runs silently on a 15-minute cron/scheduler trigger to perform hourly or daily tasks.
Dedicated Chrome Profile A sandboxed browser environment holding the cookies, caches, and logins for your Naukri account.
Naukri.com Portal The target web server receiving direct HTTPS traffic directly from your local Chrome instance.

Technical Mechanics:

  • Dedicated Profile Directory: The app creates a custom folder (.naukri-chrome-profile) in your local AppData so that automation does not interfere with your personal daily browser.
  • Playwright & CDP: The application launches Google Chrome with remote debugging enabled. Playwright connects to Chrome via port 9222 and automates interaction with the Naukri pages.
  • Background Schedulers & Constraints: If native OS scheduling is enabled, a system script is registered (using Crontab on Linux, LaunchAgents on macOS, or Task Scheduler on Windows). It runs every 15 minutes to inspect your refresh queue. If the scheduled time for headline refresh or resume upload has arrived, and it fits within your configured active time window, the task triggers. Otherwise, the script exits immediately with zero resource usage.

4. First-Time Setup

To set up Naukri Update for the first time, follow these steps:

  1. Start the Application: Upon launching, the First-Run onboarding wizard will guide you.
  2. Review the Privacy Agreement: Understand how your data is handled.
  3. Enter Naukri Credentials: Provide your Naukri login email, password, and profile URL.
  4. Select Your Resume PDF: Choose your authoritative resume file. The app copies this to its local directory.
  5. Enable Scheduling: Choose your preferred execution times for the automations.
  6. Connect Chrome: Connect the dedicated Chrome browser and log in. If prompted, complete OTP/CAPTCHA verification in that window.

5. Connecting Naukri

To connect the application to Naukri, click the Connect Chrome button on the Dashboard. This will launch a dedicated Google Chrome instance controlled by the application via Chrome DevTools Protocol (CDP) on port 9222.

If you are already logged in to Naukri in this dedicated browser, the application will detect the active session and show a "Connected" state. If you are not logged in, the application will use the credentials you configured to authenticate automatically. If Naukri presents an OTP or CAPTCHA, the automation will pause and display "Please complete OTP/CAPTCHA in the Chrome window." Complete it manually in the opened Chrome window. The application does not attempt to bypass security protections.

6. Naukri Credentials

The application requires your Naukri email and password to log in automatically when your session expires.

Security Disclosure: Your Naukri credentials are saved locally in plain text inside the .env configuration file located in the application data directory. They are not encrypted. They are never sent to our servers and are omitted from all application logs.

Access to these credentials is restricted to users who have local file access to your computer. You can remove these credentials at any time from Settings → Privacy & Data Management → Clear Credentials.

7. Choosing Your Resume

The application needs a valid resume PDF file to perform the daily upload automation. You can select a PDF from your computer under Settings → Resume File Source. The application validates that the file is a readable PDF (less than 2MB and starts with the %PDF header) and copies it into its local application storage folder. The application only accesses this local copy when running the upload automation.

8. Resume Automation

When the Daily Resume Upload automation triggers, the following operations occur:

  1. The app locates the local resume copy in your application data folder.
  2. The PDF structure and file size stability are verified.
  3. The app opens the dedicated Chrome browser and navigates to your Naukri profile editor.
  4. The file name is dynamically appended with the current date (e.g. Resume_29-08-2026.pdf) to prevent duplicate warning messages on Naukri.
  5. The app uploads the file and tracks the upload progress (from 0% to 100%).
  6. It waits for the success confirmation popup on Naukri.
  7. It saves the profile, reloads the page, and verifies that the active resume name on Naukri matches the uploaded dated filename.
  8. Finally, it scans the local resume directory to delete old temporary dated files, ensuring only the single source resume remains.

9. Resume Headline Automation

The Resume Headline automation updates your profile activity timestamp without changing your actual profile contents. It opens your profile, clicks the edit icon next to your headline, toggles a dot (.) at the end of the text, clicks Save, reloads the page, and verifies that the new headline is correctly saved on Naukri. This is done entirely using Playwright browser actions on the dedicated Chrome browser.

10. Scheduling

The application handles background scheduling by integrating with your operating system's native scheduler:

  • Windows: Task Scheduler (creates a task named NaukriUpdateTask running every 15 minutes).
  • macOS: LaunchAgent (creates a plist file at ~/Library/LaunchAgents/com.naukri.update.plist running every 15 minutes).
  • Linux: Crontab (adds a cron job running every 15 minutes).

When the system scheduler triggers, it launches the application headlessly with the --run-automation flag. The app checks if your scheduled automation time has arrived, connects to the browser profile, runs the required updates, and exits quietly. Additionally, when the desktop app window is open, an in-app timer checks for tasks every 60 seconds.

11. Chrome / Browser

The dedicated Chrome profile is stored locally in the .naukri-chrome-profile directory. This profile holds browser cache, cookies, and local session details for Naukri, allowing you to stay logged in. This profile is completely isolated from your main personal Chrome browser, protecting your personal browsing history and passwords from the automation. If the browser gets stuck or you want to clear all cookies, you can reset it via Settings → Privacy & Data Management → Reset Browser Session.

14. What Data Leaves Your Computer

Your data only leaves your computer to communicate directly with Naukri.com:

  • Your Naukri credentials are transmitted to Naukri's authentication endpoint during login.
  • Your resume PDF file is uploaded to Naukri's file upload servers during the resume update automation.
  • Your updated resume headline is sent to Naukri's profile updates API.

Strict Privacy Commitment: This application contains no analytics libraries, no crash reporting telemetry, no update tracker, and no third-party network connections. No data is ever sent to any application server or developers.

15. Security & Privacy

We believe in absolute transparency about security:

  • Local Security: Since credentials are stored in plain text, anyone with access to your computer's filesystem can read your Naukri password. We restrict file access permissions on Unix/Linux systems (chmod 0600), but highly recommend securing your operating system user account.
  • Log Safety: The application automatically scrubs and masks passwords (e.g. replacing them with ••••••••) before saving log files or showing them in the GUI.
  • Naukri Protection: The application cannot bypass CAPTCHAs, OTPs, or two-factor authentication. These are security measures enforced by Naukri and must be resolved manually by you.

16. Background Operation

Understanding how the application runs when closed:

  • Minimize / Close Window: Clicking the window close (X) or minimize button hides the application to your system tray. The automation continues to run in the background.
  • Quit Application: Right-clicking the tray icon and selecting Quit completely shuts down the app. However, scheduled system tasks (cron/LaunchAgent/Windows Task Scheduler) will still launch the application in headless mode when an automation is due.
  • Close Chrome: If you close the dedicated Chrome browser window, the app updates the Dashboard to "Disconnected". When the next scheduled run occurs, the system scheduler will automatically launch Chrome again.

17. Notifications

The application sends system notifications when background tasks complete or fail (e.g. Profile Refreshed, Resume Uploaded, or Headline Refresh Failed). These notifications never contain passwords, emails, or personal details, ensuring your privacy is protected if other users view your notifications.

18. Troubleshooting

Naukri is showing "Disconnected"

Click Connect Chrome. If Chrome opens, log in to Naukri manually and solve any verification steps. Once your profile page is visible, the dashboard will update to "Connected".

Resume Upload Fails

Ensure that your resume is a valid PDF and is not opened or locked by another program. Check that you have a stable network connection. You can check the detailed error description in the activity logs.

Chrome Window Closed unexpectedly

The application detects browser closures within 2 seconds, updating its status to "Disconnected". Simply click Connect Chrome again to restore connection.

19. Common Errors

  • CDP Endpoint Unreachable: Chrome failed to launch or crashed. Close the application, check if Google Chrome is installed, and try restarting.
  • Not on authenticated profile page: The browser was redirected. This usually means Naukri logged you out. Click Connect Chrome and log in again.
  • Path traversal warning: Your resume file path configurations point outside the secure application directory. Please select your resume again using the settings file picker.

20. Logs & Diagnostics

Under the Activity Logs tab, you can view the execution history. If an automation fails, the application saves a debug screenshot at naukri-refresh-error.png inside the configuration folder so you can see exactly why it failed. The logs are masked and never store plain-text passwords.

21. Disconnecting / Removing Data

You can remove your data using the controls in Settings → Privacy & Data Management:

  • Clear Credentials: Removes your email and password from the local .env file.
  • Remove Resume: Deletes the resume PDF from the local data folder and clears the path.
  • Reset Browser Session: Deletes cookies, history, and Naukri session data in Chrome.
  • Reset Entire Application: Deletes configuration files, logs, resumes, and browser profiles, restoring the application to the first-run state.
  • Uninstall: Quit the application, delete the configuration folder (data folder), delete the application executable, and clear your OS scheduler (using Task Scheduler, launchctl, or crontab).

22. Updating the Application

Naukri frequently updates its user interface, which may break automation selectors. When this happens, we release updates. Since this app contains no auto-update servers (for privacy reasons), you must download the latest release manually from our official GitHub repository. Updates include selector bug fixes, security enhancements, and compatibility adjustments.

24. FAQ

Why do you need my Naukri password?

The password is used by Playwright to sign in to your Naukri account if the dedicated browser session expires, ensuring that background updates run without interruption.

Can the application see my normal Chrome passwords?

No. The dedicated Chrome profile is entirely separate from your personal Chrome profile. The automation cannot read your personal browser history, cookies, or saved passwords.

Does the application have access to my entire computer?

No. The application only accesses files inside its dedicated configuration directory and the specific PDF file you select as your resume. It does not scan or read other areas of your hard drive.

Does this bypass CAPTCHA?

No. CAPTCHA is designed to block automated bots. If Naukri presents a CAPTCHA, the automation pauses and waits for you to solve it manually in the Chrome window.

25. Advanced / Technical Details

For developers and advanced users, the application manages the following configuration settings in the .env file:

  • NAUKRI_EMAIL: Naukri username
  • NAUKRI_PASSWORD: Naukri login password
  • NAUKRI_PROFILE_URL: URL to profile editor
  • REFRESH_MODE: interval or fixed_time
  • REFRESH_INTERVAL_HOURS: Hours between headline updates
  • REFRESH_INTERVAL_MINUTES: Minutes between headline updates
  • REFRESH_TIME: Time for headline updates (24h format)
  • RESUME_UPDATE_ENABLED: true or false
  • RESUME_UPDATE_TIME: Time for resume upload (24h format)
  • RESUME_FILE: Path to active resume PDF
  • REFRESH_WINDOW_ENABLED: true or false
  • REFRESH_WINDOW_START: Start of execution window
  • REFRESH_WINDOW_END: End of execution window

You can run automation directly from the terminal inside the project directory using: node naukri-profile-refresh.js --refresh-headline or --upload-resume.
